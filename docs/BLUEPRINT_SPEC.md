# Blueprint仕様

現行Provider（Step 7i更新）：OpenAI Responses API `gpt-6-luna`のStructured OutputsでEditor Blueprint v1 JSONを生成する。既存v1 schema / Effect / Binding / Region / Renderer契約は変更しない。Provider向けstrict JSON Schemaは共通Blueprint schemaから生成し、nullable optional fieldsはGo検証前に正規化する。Go validatorが最終的な必須項目・範囲・参照整合性を判定する。旧Gemini記述はStep 5〜7h当時の履歴。

DECIDED：ProjectはBlueprint、Feature Timeline、背景素材、再現用メタデータを持つ。BlueprintはScene/Regions/Layers/Effects/Bindings/Sectionsを分離する。正式JSONスキーマは未確定。

DECIDED：Regionは正規化座標の矩形または多角形。Effectは表現、Bindingはfeatureと制御方式を定義する。プレビューと動画出力で同一のマスク処理を使う。

DECIDED：DrumsからKickイベントを推定し、BassはRMS等の連続値を生成する。100HzはPROPOSEDであり確定値ではない。

DECIDED：同一Blueprint、特徴量、再生時刻、Renderer版、seedから同じ描画命令を得る。Attack/Releaseや粒子はシーク順序に依存させない。エンコード結果のバイト一致は要件外。

FACT（最小Rendererの暫定契約）：時刻単位はms、特徴量は時刻昇順の `{timeMs, value}` 系列、区間内は線形補間、範囲外は端点値（空系列は0）、値は0..1へclampする。出力命令はCanvas非依存の矩形fill命令。これは固定デモ用で、正式schemaや任意Blueprint検証を確定しない。

FACT（Python Island schemaVersion 1）：既存Frontend必須キー`durationMs` / `bassEnvelope` / `kickEvents`を維持し、時間は音源先頭基準ms、continuous featuresは10ms hop（100Hz）で出力する。Bass Envelope/Drum Energy valuesはfeature系列ごとの全区間95 percentile RMSで除して0..1へclamp。Kick eventはdrums stemの短時間35-120Hz立ち上がり、35-80Hzと100-250Hz比、80ms減衰を組み合わせて推定し、ms時刻配列とparallel strength配列を返す。混合stemからの推定であり、確定ラベルではない。`featureHopMs`、`schemaVersion`、`analysisVersion`等は追加情報。100Hz採用はPython出力についてのDECIDEDであり、正式Project/API Timeline契約への決定ではない。

FACT（Step 7k-11b）：Kick推定は前向きの局所中央値と低域rise score、35-80Hz / 100-250Hz比、80ms後の減衰確認を用い、近接peakは120msのrefractoryで抑制する。Strengthは検出scoreの全イベントp99で正規化し0..1とする。Timeline v1の`kickEvents` / `kickEventStrengths`、時刻/範囲/整列契約は変更しない。既存方式との合成ラベル評価ではSnare/Tom誤検出を抑え、高速ダブルKickを分離し、既存Kick fixtureを維持。実demo曲には正解ラベルがなく、実曲Precision/Recallは未確認。

FACT（Step 7k-2加法拡張）：Timeline schemaVersion 1のまま、任意の`snareEvents`/`snareEventStrengths`、`vocalsEnvelope`、`otherEnvelope`、`musicEnergy`を追加する。Snare EventsはDemucs drums stem中の700–10000Hz transient peakに基づくsnare-like推定で、snare単独分離や確定ラベルではない。Drum Energyは従来の`drumEnergy`系列を直接参照し重複系列を作らない。Vocal/OtherはBassと同じ10ms RMS・系列別95 percentile normalization。Music Energyは既存decode PCMの同じ方式。event時刻は昇順・重複なし、parallel strengthは0..1。旧Timelineで新sourceが欠ける場合、そのBindingは値0の非活性となる。

FACT（Binding source v1）：Event型は`kick.events`と`snare.events`、Continuous型は`bass.envelope`、`drums.energy`、`vocals.envelope`、`other.envelope`、`music.energy`。従来UIで両sourceを選択できたPulse Scale/Glow/Rotation/Particles/Waveform Bars/Radial Bars/Wave Ringは両型に対応。Particle Burst/ShockwaveはEventのみ、Particle Trail/Ripple/Oscilloscope LineはContinuousのみ。Binding strength/threshold/attack/releaseの評価則は維持。Timeline/Blueprint/Projectのversionは変更しない。

FACT（Visual Editor schema v1、Step 7k-1時点）：`frontend/src/editor-model.ts`で背景（solid/linear gradient/単一PNG・JPEG data URL）、矩形/多角形Region、12種Effect、effectごとに必須の1 Bindingを定義。座標は0..1で領域外を拒否し、多角形は3..64頂点かつ非ゼロ面積。Region重複は許容し、Effect配列順で重ね、各命令をそのRegionのclip内に描く。固定Timelineはms単位のBass EnvelopeとKick Event。Bindingは閾値後のBass/Kick値を20msの決定論的Attack/Release followerで平滑化しstrengthを乗じる。形式・評価則はEditor schema v1であり、サーバー/APIや全Project Blueprintの正式契約ではない。

FACT（Step 7k-2 Binding source）：Event型は`kick.events`/`snare.events`、Continuous型は`bass.envelope`/`drums.energy`/`vocals.envelope`/`other.envelope`/`music.energy`。従来両sourceを選べたPulse Scale/Glow/Rotation/Particles/Waveform Bars/Radial Bars/Wave Ringは両型、Particle Burst/ShockwaveはEvent型、Particle Trail/Ripple/Oscilloscope LineはContinuous型。sourceごとの入力特徴量はTimeline v1のoptional fieldとして検証し、欠損時は非活性にする。Blueprint v1とProject形式は変更しない。

FACT（Step 7k-3 optional color contract）：Blueprint v1 root may contain optional `globalGradient` with exact fields `startColor`, `middleColor`, `endColor` (strict `#RRGGBB`) and `angleDeg` (0..360). Its Canvas-wide coordinates and stop positions are fixed at 0/0.5/1; default colors are `#22d3ee` → `#8b5cf6` → `#ec4899`. Effects may contain optional `colorMode` (`global-gradient` or `custom`). Missing `colorMode` means legacy custom `color` and preserves prior appearance; newly added Effects select `global-gradient`. A global-mode Effect with a missing palette uses the default palette. Colors are static. Existing Blueprint, `.arvproj v1`, Cloud Envelope / Project Document v1 remain version 1. OpenAI Structured Output normalizes its nullable optional fields to the default palette and global mode before ordinary Blueprint validation.

FACT（Step 7k-3 in-place type change）：Editor replaces the selected Effect object at the same array position while retaining its `id`, `regionId`, color configuration, and associated Binding record/id/settings. Effect-specific parameters are rebuilt using the same defaults as Add Effect. If the existing source is incompatible with the new Effect, it switches to `kick.events` for Event-only Effects or `bass.envelope` for Continuous-only Effects; compatible sources are kept. No geometry or Renderer responsibility changes.

FACT（Step 7h-1 Phase A）：Editor Blueprint v1に`radial-bars`（centerX/Y、radius、bars、barLength、lineWidth）と`wave-ring`（centerX/Y、radius、amplitude、points、lineWidth）を追加。Effectは既存のBass/Kick Bindingを使い、正規化パラメータ範囲はFrontendとGo validatorで検証する。Wave Ringのamplitudeは基本radiusに対する最大変形率。Radial Barsは回転付き矩形命令、Wave RingはTimeline由来座標の閉じたpath命令で、いずれも既存RendererのRegion clipを通る。Blueprint/schema versionは1を維持し、`.arvproj v1`とCloud Project validatorも両Effectを受け付ける。古いアプリ版はこれらの追加Effectを知らないため、新Effectを含むProjectを旧版へ戻して編集できる互換性は保証しない。

FACT（Step 7h-2 Phase A）：Editor Blueprint v1に`particle-burst`（originX/Y、directionDeg、spreadDeg、speedPxPerSec、lifetimeMs、count、sizePx）と`particle-trail`（samples、trailMs、sizePx、amplitude）を追加。Burstは`kick.events`、Trailは`bass.envelope` Bindingを必須とし、Frontend/Go validatorで参照元と数値範囲を検証する。Burstはイベント時刻・Effect ID・Seed・粒子indexから初期条件を計算し、過去32イベント、1イベント32粒子まで描画する。Trailは時刻から最大128点を再サンプルし、過去フレーム状態を保持しない。双方とも既存Region clipと`renderEditorFrame`を使用し、Blueprint v1、`.arvproj v1`、Cloud Envelope v1を維持する。Gemini schemaは構造・共通スカラー範囲・Effect kindを制約し、Effect別必須fieldと厳密範囲はGo validatorが独立検証する。旧アプリ版との新Effect編集互換は保証しない。

FACT（Step 7h-3 Phase A）：Editor Blueprint v1へ`ripple`（centerX/Y、waves、periodMs、radius、amplitude、lineWidth）と`shockwave`（centerX/Y、maxRadius、lifetimeMs、lineWidth）を追加。Rippleは`bass.envelope`を周期サンプルし最大6 path ringsを生成し、Shockwaveは`kick.events`から直近32生存イベントを寿命評価する。両方ともCanvas 2D path、既存Region clip、`renderEditorFrame`を使い、履歴状態を持たない。Glow Brightnessには任意の`glowIntensity`（0..2）を追加し、指定時は発光層と明瞭な中心の2層を描く。項目がない既存Glowは従来の1命令描画のまま。Blueprint v1、`.arvproj v1`、Cloud Envelope v1は維持。Gemini schemaは新Effect kindとパラメータを提示し、effect別の必須項目・source・範囲はGo validatorが検証する。

FACT（Step 7k-1）：既存Radial Bars/Wave Ring/Particle Burst/Particle Trail/Ripple/Shockwave/Glowに任意描画パラメータを加え、指定時のみ鋭いスパイク、高サンプル波形、強い発光/不透明度/衝撃表現を有効化する。未指定の既存Effectは従来描画契約を維持する。`oscilloscope-line`はhorizontal/radial配置の疑似波形で、Feature Timeline Bass Envelopeから時刻・seed・effect IDに基づき決定論的に計算する。raw PCM、Timeline schema、Blueprint v1、`.arvproj v1`、Cloud Envelope v1のversion変更はない。Frontend/Go validatorとOpenAI Structured Output schemaを同期する。古いクライアントが新Effect/任意fieldを編集できる保証はない。

# Step 6のProjectコンテナ

ローカル`.arvproj` v1コンテナは既存のEditor Blueprint v1とFeature Timeline v1をschema変更せずに保存する。Renderer／解析version metadata、Blueprint seed、任意の埋め込み音源も保存する。Step 7k-17以降の保存では`metadata.musicSummary`（Music Summary v1）も任意で保持する。旧v1ファイルでこの項目がない場合はSummaryなしとして読み込む。Summaryを含むファイルは対応する解析済みcrop WAVも必要とし、Summary durationはTimeline duration、Summary fileBytesは埋め込みWAVサイズと一致しなければならない。背景画像のdata URLはBlueprint内に保持する。読み込み時は、Editorへ復元状態を反映する前に、ファイルサイズ（64 MiB）、各version、Blueprint／Timeline参照、素材の形式・サイズ（音源32 MiB）、SHA-256、および存在するMusic Summaryの内容を検証する。未対応versionは拒否する。コンテナversion 1の後方互換な加法拡張であり、既存v1の無音声ファイルとSummaryなしファイルを引き続き読み込む。`.arvproj`は平文JSONであり、機密情報を保護する`.arvb`の代用にはならない。

FACT（Step 7k-4〜7k-7 addendum）：Feature Timeline v1 may include `waveformPeaks` with exact metadata `sampleIntervalMs:20`, `windowSamples:882`, `normalization:"signed-full-scale"` and exactly `music`, `drums`, `bass`, `vocals`, `other` arrays. Each signed `{min,max}` pair is finite in [-1,1], min≤max, count equals ceil(durationMs/20), cap 12,000. Old timelines omit this field. `waveform-line`, `waveform-peak-bars`, and `waveform-ring` read the selected continuous source peak array (event sources map to drums peaks only when their event data exists); absent data produces no waveform commands. `waveform-peak-bars` is named distinctly because legacy `waveform-bars` retains its envelope-based v1 behavior. Peaks are Timeline data, never Blueprint/AI output. All effects accept the seven strict Binding source enums; Event→Continuous uses deterministic decaying intensity, Continuous→Event emits rising crossings with a 120ms minimum interval. Timeline/Blueprint/Project remain v1.

FACT（Step 7k-11a）：Feature Timeline v1 may add `frequencySpectrum`: 20ms hop, 4096-point Hann STFT at the decoded 44.1kHz PCM rate, 32 logarithmically spaced bands from 40Hz to `min(16kHz, Nyquist)`. `values` is time-major uint8 quantization (0..255), length `ceil(durationMs/20) * 32`; normalization is whole-clip 99th-percentile of positive `log1p(32 * bandRMS)` values. Silence maps to zero. This compact array is not included in Blueprint or AI prompt features. `spectrum-bars` and `spectrum-line` use the music spectrum for bar/line shape; their existing seven-source Binding adds response strength. Timeline values are optional, and absent Spectrum leaves both Effects inactive. Effect parameters are Blueprint v1 additions; the UI category `EQ / Spectrum` is derived from kind and is never persisted. API's 2MiB request cap is unchanged; a 60s Timeline with signed peaks and quantized Spectrum is tested below the cap. Project/Cloud/Blueprint/Timeline versions remain v1.

FACT（Step 7k-18 circular pixel geometry）：`pulse-scale`、`wave-ring`、`waveform-ring`、`ripple`、`shockwave`、`radial-bars`およびradial `oscilloscope-line`の円・放射距離は、割り当てRegionのStage pixel短辺を基準に同一X/Y pixel半径へ変換する。中心位置は従来どおりRegion-local normalized `centerX` / `centerY`、またはEffect仕様のRegion中心を使う。Wave Ring / Waveform Ringの音響変形は半径方向に維持し、Region shapeのclip、opacity、Binding、draw orderとPreview/WebM共有`renderEditorFrame`は変えない。Blueprint schema、radius/scale値、保存versionは不変。

FACT（Step 7k-8 BPM rotation）：`radial-bars`、`wave-ring`、`waveform-ring` may carry the all-or-none optional fields `rotationMode` (`continuous` / `triggered`), `beatsPerRevolution` (4/8/16/32), `rotationDirection` (`clockwise` / `counterclockwise`), and `initialAngleDeg` (-360..360). New Effects default to continuous, 8 beats/revolution, clockwise, 0 degrees. Legacy Blueprints without these fields retain their former static geometry. `FeatureTimeline` v1 may carry optional paired `bpm` and `bpmSource` (`kick-estimated` / `fallback`); fallback is exactly 120 BPM, estimated values are constrained to 60..180 BPM. Old Timeline without BPM uses renderer fallback 120 BPM. Constant BPM does not encode beat phase or exact beat positions. `degreesPerSecond = BPM × 360 / (60 × beatsPerRevolution)`. Triggered rotation integrates the deterministic Binding follower from t=0; angle is derived from Timeline, Blueprint, and time, never previous frame state. Blueprint/Timeline/Project/Cloud remain v1.

## Step 7k-9 optional Effect opacity and Wave Ring layers

Blueprint v1 Effects may carry `opacity` in the inclusive range 0..1. Omission means 1 and preserves legacy appearance; zero is valid and renders fully transparent while remaining editable. Renderer multiplies this value by each draw command's existing alpha. All 15 Effect kinds accept the field.

`wave-ring` may carry `layerCount` (integer 1..10), legacy `layerRadiusStep` (0..0.1), `layerAngleOffsetDeg` (0..360), and `layerAmplitudeDecay` (0.5..1). Old Blueprints omit these and render one layer. UI-created Wave Rings default to four layers, angle step 0 (automatic equal spacing), and amplitude decay 0.9. A zero angle step means an angular step of `360 / layerCount`; a positive value means the manually specified separation between adjacent layers. All layers use the same radius; `layerRadiusStep` remains accepted for save compatibility but has no Wave Ring rendering effect. Every layer samples the same feature sequence and applies the angular offset only to its rendered coordinates. These are additive v1 fields; Project and Cloud envelopes remain v1.

## Step 7k-10 visibility and audio reactivity

Effect may optionally include `visibilityMode` (`triggered` or `always`) and `audioReactive` (boolean). Missing fields preserve legacy behavior: triggered visibility and reactive input. New Editor/AI-generated Effects default to `always` + `true`. `always` keeps an Effect-specific basic shape visible at a low baseline alpha while audio response continues to control its existing deformation, intensity, or event layers. Event-only Effects may show a deterministic static baseline but do not synthesize events. Peak waveform Effects remain inactive when signed Timeline peaks are absent. `audioReactive:false` is valid only with `visibilityMode:"always"`; the Editor switches visibility to always when turning reactivity off. Continuous BPM rotation and existing raw Peak visualization are independent of Binding response.

Wave Ring `layerCount` accepts integer 1..10. Automatic `layerAngleOffsetDeg:0` means an angular step of `360 / layerCount`; positive values remain the explicit adjacent-layer step. There is no layer phase shift: the common sample sequence is rotated only in rendered coordinates. Existing `layerCount` omission remains one layer. `layerRadiusStep` is retained and validated for legacy project compatibility, but ignored by Wave Ring rendering; all layers share `radius`. All fields are optional additive Blueprint v1 extensions; Project and Cloud envelopes remain v1.

## Step 7k-11c particle parameters (Blueprint v1 additive)

`particles` accepts optional `spread` (0.1..1), `speedInfluence` (0..2), `glowIntensity` (0..2), and `baselineOpacity` (0..0.35). `particle-burst` accepts optional `swirl` (-2..2), `audioInfluence` (0..2), and `baselineOpacity` (0..0.35). Existing `count` remains the capped particle count; omitted fields preserve legacy readability and are defaulted for newly created Editor/normalized AI effects. No Blueprint version change.

## Step 7k-11d Ink Diffusion (Blueprint v1 additive)

`ink-diffusion` is a new additive Effect kind. The UI-only category `Ambient / Atmospheric` is derived from the kind and is not serialized. Optional parameters: `diffusionSpeed` (0..2, default 0.25), `flowStrength` (0..2, default 0.4), `turbulence` (0..2, default 0.3), `inkDensity` (0..1, default 0.65), `cloudScale` (0.1..2, default 0.5), and `responseTime` (0.5..10 seconds, default 3). Minimal documents may omit these fields; Editor-created and normalized AI effects use the listed defaults. The default Binding is `music.energy`. Blueprint, Feature Timeline, `.arvproj`, Project Document, and Cloud Envelope versions remain v1.

## Step 7k-11i Ink Flow and Color Mixing (Blueprint v1 additive)

`ink-flow` and `color-mixing` are additive Effect kinds in the UI-derived `Ambient / Atmospheric` category; category is not serialized. Both accept the same optional Ink parameters and validation ranges as `ink-diffusion`: `diffusionSpeed` (0..2), `flowStrength` (0..2), `turbulence` (0..2), `inkDensity` (0..1), `cloudScale` (0.1..2), and `responseTime` (0.5..10 seconds). Defaults are respectively Flow (0.45, 0.95, 0.65, 0.5, 0.65, 3) and Mixing (0.25, 0.5, 0.55, 0.65, 0.9, 4); both default to `music.energy`, Always visibility, and Audio Reactive ON in the Editor. Existing minimal/legacy Ink fields remain optional. The kinds reuse the existing bounded Ink WebGL2 context and Region-sized composite; versions remain v1.

## Step 7k-11k Color Mixing palette (Blueprint v1 additive)

`color-mixing` accepts optional `customPalette`, an array of 2..4 strict `#RRGGBB` strings. It is allowed only for the `color-mixing` kind. In `colorMode: "global-gradient"`, the existing global three-color palette drives the independent pigment sources and `customPalette` is ignored. In `colorMode: "custom"`, a present palette assigns per-source pigment colors; when omitted, legacy single-color `color` behavior is preserved. New Editor-created and normalized AI Color Mixing effects use the default palette `[#22d3ee, #8b5cf6, #ec4899]`, while the effect's default color mode remains Global Gradient. Project/API versions remain v1.
