## Findings

### Where the displayed error comes from

`frontend/src/audio-analysis.ts` maps HTTP 422 to the reported Japanese error. In the current Go handler, 422 is returned before Python runs for either (a) an invalid/missing/duplicate multipart audio part or unrecognized multipart field (`receive_audio`), or (b) a WAV that fails ffprobe format, codec, sample-rate, channel-count, or duration validation (`probe`). The current handler does not check volume. Python process failures map to 502, request size to 413, and analysis timeout to 504. Therefore the displayed “volume” hint was inaccurate and did not identify which 422 branch occurred.

### Frontend request and Gate Mode

- The cropper decodes the source in Web Audio, renders exactly the selected frames through a 44.1kHz stereo `OfflineAudioContext`, and writes a 44-byte RIFF/WAVE header followed by PCM16 samples.
- The 43.14–103.14s selection is exactly 2,646,000 frames at 44.1kHz (60,000ms), with a canonical WAV size of 10,584,044 bytes.
- The request is browser-generated multipart `FormData`: one `audio` file and one `kickGateMode` text field. The browser sets the multipart boundary. Frontend and Go tests cover Off, Soft, Middle, and Hard; omission remains Hard.
- The current Go parser explicitly accepts `kickGateMode`. A Go process started before Step 7k-25 may still run older strict multipart code and reject this new field with 422. This is a plausible cause, not a confirmed one: the Windows process version and its request-stage log were not accessible here.

### Crop validation

The repository's `audio-reactive-silent-demo4.mp3` reports 189.984s container duration. An independent FFmpeg crop at 43.14s for 60s produced a WAV that ffprobe identified as `pcm_s16le`, 44,100Hz, 2 channels, 60.000s. Decoded samples were non-silent (peak 18,389 / 32,767; RMS 4,168.64 / 32,767). The original MP3 was not modified. This confirms the time window and expected PCM representation for this available source; it is not a capture of the browser-generated bytes from the user's failing request.
