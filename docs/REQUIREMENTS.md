# 要件と受け入れ条件

全項目DECIDED（MVP対象）。以下は受け入れ条件であり、実装実績ではない。

| ID | 機能 | 受け入れ条件 |
|---|---|---|
| M01 | MP3/WAV入力 | 正常入力を受理し、不正形式を拒否 |
| M02 | PNG/JPEG入力 | 画像を表示し、不正入力を拒否 |
| M03 | 単色/グラデーション | 設定を描画へ反映 |
| M04 | 4 Stem分離 | drums/bass/vocals/otherを生成 |
| M05 | 特徴抽出 | Kick推定イベントとBass等の連続値を保存 |
| M06 | Gemini生成 | 要約と利用可能featureからBlueprint生成 |
| M07 | 検証 | 不正スキーマ・参照を拒否 |
| M08 | 音響連動描画 | 再生時刻に同期して描画 |
| M09 | 手動編集 | 効果の音源・強度・閾値・Attack/Releaseを変更 |
| M10 | Region | 矩形/多角形を作成・編集・削除し、指定外は静止 |
| M11 | 音声付き動画 | 音声同期した動画を出力 |
| M12 | 無音動画 | 音声なしの映像を出力 |
| M13 | 暗号化出力 | 素材・特徴量・版情報を含むファイルを保護 |
| M14 | 再インポート | 復元し、改ざんファイルを拒否 |
| M15 | 認証 | Supabase認証を利用し不正JWTを拒否 |
| M16 | 保存・再編集 | 所有者のみ取得・更新・削除可能 |
| M17 | 固定デモ | 未認証で固定サンプルを利用可能 |

追加完了条件：公開URL、必要なテスト、設計書との照合、コスト制限・監視、人による映像品質の受け入れ。各検証結果はreportsへ記録する。
