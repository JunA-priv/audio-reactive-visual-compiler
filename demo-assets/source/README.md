# デモ用音源の配置

このディレクトリにはローカルデモ・評価用音源を配置します。demo1〜demo3はユーザーがSuno有料プランで作成し、デモ利用目的で提供した音源です。個別の音源ごとに録音種別と処理・公開・配信の権利を確認してください。

`audio-reactive-silent-demo4.mp3`はStep 7k-23のローカル評価入力として存在しますが、録音種別・権利の記録がありません。アコースティック音源としての聴取確認も未実施です。現在は候補確認用にローカル処理しただけで、公開・配信・再配布には使用しないでください。

- 対応形式：WAV / MP3
- 上限：4分（Python Island CLIの制限）
- 音源ファイルはGit管理対象外です。
- 実音源を`frontend/public/demo/`へコピーする前に、公開・配信・改変・派生利用の権利を確認してください。
- 音源がない場合は作成・ダウンロード・合成による代用をせず、既存の固定サンプルデモを維持します。

配置後の解析手順は[`../generated/README.md`](../generated/README.md)を参照してください。
